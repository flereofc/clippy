## Clippy v0.1.0: First Beta 🎉

Clippy is a fast, lightweight clipping tool written in Rust. This is the first public beta, so expect some rough edges. Your feedback will shape what comes next.

### 📦 Download & install
1. Download **`Clippy_0.1.0_x64-setup.exe`** from the Assets section below (59.5 MB, Windows 64-bit).
2. Run the installer and follow the steps.
3. Launch Clippy from the Start menu.

> Windows SmartScreen may warn you because this beta isn't code-signed yet. Click **More info → Run anyway** if you trust the download.

To verify the file, compare its SHA-256 hash (shown next to the installer in Assets) with the one on your machine:
`Get-FileHash .\Clippy_0.1.0_x64-setup.exe -Algorithm SHA256`
